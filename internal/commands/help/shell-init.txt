Print the shell integration for zsh, bash or fish, which lets
`cg browse` cd to the repo you pick. Add it to your shell's startup
file:

  zsh (~/.zshrc):    `eval "$(cg shell-init zsh)"`
  bash (~/.bashrc):  `eval "$(cg shell-init bash)"`
  fish (config.fish): `cg shell-init fish | source`

The Home Manager module does this for you (`programs.clonager.enableShellIntegration`).

It defines a shell function named `cg` that runs the program as usual,
with `CLONAGER_CD_FILE` set to a temporary file. When you pick a repo to cd
to, browse writes its folder there, and the function cds to it once browse
exits. Every other command works just as it does without it.
